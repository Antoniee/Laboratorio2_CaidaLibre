## Instrucciones de uso y ejecución

Para ejecutar el script y verificar las pruebas controladas de consistencia física, sigue estos pasos:


1. **Instala o revisa si tienes instalado:** Python 3.12 o  una versión superior. 

2. **Clona o descarga este repositorio.**

3. **Ejecuta el programa principal desde la terminal:**

  ```bash
   python caida_libre.py
   ```
